# Data Science Tools and Ecosystem

Introductory course notebook covering data science languages, libraries, tools, and simple Python calculations.

## Notebook

[Open DataScienceEcosystem.ipynb](DataScienceEcosystem.ipynb)

## Topics covered

- Lists of commonly used data science languages, libraries, and tools.
- Markdown headings, lists, and tables in a notebook.
- Arithmetic expressions and converting minutes to hours with Python.

The language and library lists are part of the coursework, rather than a claim of experience with every listed tool.

## Viewing and running

GitHub renders the notebook directly. To run its Python cells, download it and open it with Jupyter Notebook or JupyterLab using a Python 3 kernel.
